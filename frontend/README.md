# 💻 VibeConnect Frontend Client

Independent React 19 + Vite + Tailwind CSS frontend for VibeConnect.

## 📦 Setup & Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run in development mode:**
   ```bash
   npm run dev
   ```
   Opens at: `http://localhost:3000`

3. **Build production bundle:**
   ```bash
   npm run build
   ```

## 🔗 Server Connection

The Vite dev server proxies API calls and WebSocket connections to the backend server running on `http://localhost:5000`. Make sure the backend server is running before opening the app.
