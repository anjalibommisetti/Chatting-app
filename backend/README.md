# 🚀 VibeConnect Backend Server

Independent Node.js + Express + Socket.IO + WebRTC backend for VibeConnect.

## 📦 Setup & Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run in development mode (with auto-reload):**
   ```bash
   npm run dev
   ```

3. **Run in production mode:**
   ```bash
   npm start
   ```

## 🌐 Endpoints

- **Server URL:** `http://localhost:5000`
- **REST API Base:** `http://localhost:5000/api`
- **WebSocket Endpoint:** `ws://localhost:5000`
- **Uploaded Media:** `http://localhost:5000/uploads`
